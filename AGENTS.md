# MultiplayerJam project guidance

- Treat this repository as a Unity project for all development, debugging, design, testing, build, graphics, UI, physics, networking, and performance work.
- Use the installed Unity plugin and begin with the `unity:using-unity` skill for every Unity-related request, including advice questions, before answering or making changes.
- When work requires inspecting, running, testing, or controlling the project in the Editor, prefer the Unity plugin's Editor-aware workflow and the available Unity application.
